# @buildrail/cli

The `buildrail` command-line interface.

## Status

**BR0 — no functional CLI.** This package currently contains placeholder
command files under [`src/commands/`](src/commands/) with no
implementation. Each file notes which development phase is expected to
implement it.

The CLI skeleton (`--help`, `init`, `status`) is planned for BR1. See
`docs/development/BR1.md` and `docs/ROADMAP.md` at the repository root.
