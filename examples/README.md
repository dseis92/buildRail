# Examples

Reference examples demonstrating BuildRail-governed projects. As of BR0,
these directories contain only descriptive READMEs — no actual example
applications exist yet. Building out a real reference example is part of
BR8 (End-to-End Dogfood).

- [`nextjs-supabase/`](nextjs-supabase/) — full-stack TypeScript app with
  database/auth and protected migrations
- [`simple-node/`](simple-node/) — minimal Node application demonstrating
  minimal BuildRail configuration
- [`python-api/`](python-api/) — Python API demonstrating that BuildRail's
  concepts are not JavaScript-specific
